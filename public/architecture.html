6. Docker Deployment

🐳 docker-compose.yml

  • 2 services: db + app
  • Volume: mysql_data (persistent)
  • Port: 127.0.0.1:3000
  • depends_on: db (healthy)

📦 db (MySQL 8.0)

  • init-db.sql on first start
  • auto-migrate.ts on app start
  • UTF-8 (utf8mb4)
  • Healthcheck: mysqladmin ping

⚡ app (Next.js)

  • node:20-alpine (3-stage build)
  • next build --webpack
  • Standalone output mode
  • NODE_OPTIONS: 1536 MB max
